# v0.8.0 Benchmark 报告 —— 可观测性的成本

生成时间：见 `results.json`（`--iterations=20000`）。

## 结果

| 操作 | 单次开销 | 吞吐 | p95 |
| --- | --- | --- | --- |
| 起一个 Span 并结束 | 5.84 µs | 171,362 ops/sec | 7.49 µs |
| 不采样时（直接返回 null） | 0.27 µs | 3,688,153 ops/sec | 0.24 µs |
| Span + 4 个属性 | 5.62 µs | 178,023 ops/sec | 7.18 µs |
| Counter 自增 | 1.06 µs | 940,453 ops/sec | 1.14 µs |
| Histogram 观测 | 0.85 µs | 1,173,072 ops/sec | 0.98 µs |
| Prometheus 序列化（500 序列） | 880 µs | 1,136 ops/sec | 1,154 µs |
