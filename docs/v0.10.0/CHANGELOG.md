# Changelog — v0.10.0（2025 · 工程化工具链）

> 文档由契约生成，而不是手写 —— 手写必然漂移，而漂移的文档比没有文档更糟。

## 新增能力

### `nofaultctl openapi`
- 由同一份契约产出 OpenAPI 3.0 文档（纯函数 `openApiDocument()`）
- `:id` → `{id}`；`@Path` → `in: path`；`@Query` → `in: query`
- 无必填字段时**省略** `required` 键（空数组语义相反）
- 无响应类型用 204；所有操作都带上 422

### `nofaultctl dev`
- 监听目录变化自动重启，默认防抖 150ms
- 重启前**等旧进程真的退出**（否则抢端口，表现为"改了没生效"）
- 重启期间的变更不丢（记一笔，结束后立刻再重启）
- 进程自己崩溃**不自动重启**（避免在坏代码上反复启动刷屏）

### `nofaultctl doctor`
- 检查 Node 版本、`package.json` 的 type、装饰器元数据、`reflect-metadata`、源码目录
- **解析 tsconfig 的 `extends` 链**（不解析会大面积误报）
- 每项都给出可执行的修复建议；有 fail 时退出码 1，可直接进 CI

## 关键设计决策

| 决策 | 理由 |
| --- | --- |
| 文档由契约生成 | 手写必然漂移，而漂移的文档比没有文档更糟 |
| 无必填时省略 `required` 键 | `required: []` 在部分工具里被当成"全部必填" |
