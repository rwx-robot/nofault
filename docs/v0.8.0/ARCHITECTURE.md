# v0.8.0 架构：可观测性

## 一句话

**Metrics 告诉你"出问题了"，Trace 告诉你"是哪一步出的问题"，日志告诉你"当时发生了什么"**——
三者各管一段，缺一个排查就要靠猜。

v0.3.0 只做了 traceId **透传**（日志能串起来）；
这一版补上 **Span 上报**（时长、属性、状态、采样）与 **Metrics**（Counter / Gauge / Histogram）。

## 一、Trace：Span 树

一次请求 = 一棵 Span 树：

```
GET /api/users/:id                    ← 服务端 Span
├── repository.findById               ← 子 Span
└── rpc call user-service.profile     ← 子 Span（跨进程，靠 traceId 续上）
```

**父子关系靠"当前活动的 Span"建立**，而不是靠显式传参：

- 起 Span 时，从请求上下文里取出当前 Span 作为父，并把自己登记为新的当前 Span
- 结束时**还原**上一个（Span 是嵌套的，不还原就会挂错父）

这个"当前"必须放在**请求上下文**里（v0.3.0 的 `AsyncLocalStorage`）——
用模块级变量在并发下必然串号。

### 采样在创建时决定，不在结束时

`startSpan()` 不采样时**返回 `null`**，而不是返回一个"空 Span"。

理由：起一个 Span 要 5.84µs，其中大部分是 ID 生成。
先建再丢，等于为每条被丢弃的链路全额付费——采样率降到 1% 也省不下来。

代价是调用方要写 `span?.end()`。这个别扭是**故意的**。

### 只有结束的 Span 才会被导出

未结束的 Span 只有两种可能：代码 bug，或进程被杀。
留着它们只会让 trace 出现"永远在路上的请求"。

## 二、Metrics：三种类型

| 类型 | 语义 | 例子 |
| --- | --- | --- |
| Counter | 只增不减的累计值 | 请求总数、错误数 |
| Gauge | 可上可下的瞬时值 | 在途请求数、连接池大小 |
| Histogram | 分布（桶计数） | 请求耗时、响应大小 |

**Histogram 只存桶计数，不存样本**。
几千 QPS 下存全部样本必然 OOM，代价是分位数只能给到"所在桶的上界"——
这与 Prometheus 的 `histogram_quantile` 是同一个取舍。

### 标签基数爆炸

`route` 标签如果直接用请求路径，`/users/1` 和 `/users/2` 是两个序列——
用户一多，内存和抓取耗时一起爆。

必须**收敛**：把路径里的数字段替换成占位符（`/users/:id`）。
这是接入指标时最容易漏、也最容易在上线后才炸的一步。

## 三、三条容易写错的地方

1. **错误状态码要在 `catch` 里记，不能在 `finally` 里读** ——
   此时框架还没把异常映射成响应状态码，`finally` 读到的是默认的 200。
   结果就是"监控上零错误，实际全线 500"

2. **标签要收敛**（见上）

3. **traceId 要回给客户端**（`x-trace-id`）——
   否则用户报"我这边报错了"时，你没有任何办法把他的请求和你的日志对上

## 四、默认导出器是内存的

可观测性**不该要求先装一套后端才跑得起来**。
`InMemoryExporter` 让单元测试能直接断言"这个 Span 被记下来了"，
也让示例开箱可跑。接 Jaeger / OTLP 只是换一个 `Exporter` 实现。

## 五、本版踩到的坑

1. **子 Span 拿不到父 Span** —— "当前 Span"没放进请求上下文，
   `parentSpanId` 一直是 `undefined`，trace 树退化成一堆散点
2. **Span 开销 13.93µs** —— 瓶颈全在 ID 生成：
   `getRandomValues` 2.9µs + `padStart` 拼字符串 5.8µs。
   改成十六进制查表 + 一次填充产出两个 ID 后降到 **5.84µs**
3. **错误请求被统计成成功** —— 见上文第一条
4. **分位数断言写错** —— 桶式直方图给的是桶上界，不是精确值

## 六、已知限制

- 只有内存导出器，没有 OTLP / Jaeger 实现
- 无日志与 Trace 的自动关联（traceId 要自己写进日志）
- 指标无持久化，进程重启清零
- 无告警规则
