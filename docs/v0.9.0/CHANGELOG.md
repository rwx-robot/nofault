# Changelog — v0.9.0（2024 · 微服务全家桶）

> 前八版交付的是能力，这一版负责把它们接起来，并补上分布式环境下不能省的四样东西。

## 新增包 `@nofault/micro`

- **Snowflake ID**：63 位（时间戳 / 数据中心 / 机器 / 序列号）
  - 时钟回拨：容忍范围内自旋等过去，超出则抛 `ClockMovedBackError`
  - 序列号耗尽时**等到下一毫秒**，不回绕
  - 返回 `bigint` / 字符串，不返回 `number`（63 位超过 MAX_SAFE_INTEGER）
- **分布式锁** `DistributedLock` + `MemoryLockBackend`（可换 Redis）
  - 释放时校验 token，绝不释放别人的锁
  - 自动续期 watchdog，续期失败即停
  - `run()` 用 finally 释放
- **调度器** `Scheduler`：5 段 cron（`*`/步长/区间/列表）+ `every` / `fixedDelay` / `after`
  - cron 的日与周是**或**关系（与 Unix cron 一致）
  - 默认不补跑、不允许重叠
- **事件总线** `EventBus`：订阅者错误隔离、退订函数、`sequential` 选项、可插拔 Bridge
- **一键装配** `Microservice`：按序执行钩子，逆序停机，启动失败自动回滚

## 关键设计决策

| 决策 | 理由 |
| --- | --- |
| ID 返回字符串而非 number | 63 位超过 MAX_SAFE_INTEGER，转 number 会静默丢精度 |
| 序列号耗尽要等待而不是回绕 | 回绕产生重复 ID，要几个月后才被发现 |
| 释放锁校验 token | 不校验会释放别人的锁，等于没加锁 |
| 默认不补跑错过的任务 | 补跑会在重启瞬间涌入几十个任务，把服务再打挂 |
| 默认不允许任务重叠 | 慢任务越积越多 = 事实上的自我 DoS |
| cron 日与周是或关系 | 实现成与，`0 0 1 * 0` 永远不触发 |
| 订阅者抛错不能影响其他人 | 否则某个模块的 bug 会断掉整条事件链 |
| 先迁移再监听、先关监听再注销 | 反过来就有"半初始化实例在收流量"的窗口 |
| 就绪标记最后打开 | 在那之前探针必须如实说"还不能服务" |
