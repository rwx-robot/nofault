## 差距总结

**已对齐**：核心运行时、Web 全栈、RPC 骨架、数据访问、代码生成、治理四件套、可观测性
（含 OTLP 导出、traceId 关联日志、读写分离——原"下一步可补"三项已全部落地）。

**明确不做（有取舍理由）**：
- 二进制协议：JSON 便于调试，性能差距在 JIT 之后并不决定成败
- JOIN / 多数据源：交给 Repository 手写 SQL，而不是再做一个 ORM
- 自适应限流 / 选主：需要真实集群环境才能验证，单机实现了也是自欺

**无未对齐遗留项。**
