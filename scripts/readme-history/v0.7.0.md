# nofault

> 严格遵循 **Node.js / NestJS 生态规范**的 Node.js 微服务框架，参考行业最佳实践设计。

**当前版本：v0.7.0（服务治理）**

---

## 是什么

nofault 把业界主流框架的能力矩阵搬到 Node.js：代码生成、约定优于配置、内置服务治理。

补齐治理四件套：令牌桶限流、三态熔断器、舱壁并发隔离、指数退避。

## 架构概览

**限流挡流量、熔断别再打坏掉的下游、舱壁限制并发、退避把重试打散**—— 四件事互不替代，缺一个就会在特定故障模式下裸奔。
